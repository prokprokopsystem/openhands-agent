## Режимы проекта

- **TEST MODE** — текущая жёсткая изоляция, пустой `test-workspace`, без доступа к внутренним интеграциям.
- **WORK MODE** — тот же Agent Canvas, systemd, supervisor и контейнер, дополненные отдельным постоянным профилем разрешений и инструментов.

Переход в WORK MODE не требует переписывания базового deployment. Рабочие полномочия подключаются отдельной конфигурацией после успешного тестового запуска.
