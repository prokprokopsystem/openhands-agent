# OpenHands Agent — Архитектура

**Актуализировано:** 24 октября 2026. Принятый курс — DEC-023, без дополнительного broker/connector. Это описание границ и известных связей, не подтверждение готовности системы.

## Рабочий контур

- Браузер → Canvas 1.6.1 на mini-server → Agent Server → выбранный LLM-профиль DeepSeek через https://api.deepseek.com/v1.
- Профиль агента содержит llm_profile_ref; отдельная метка Default в списке LLM не заменяет эту ссылку.
- Telegram использует существующий gateway к Canvas/Agent Server. Его функционирование после текущих изменений ещё нужно проверить.
- OpenHands работает в Docker; существующий lifecycle через systemd сохранён. Новую схему автозапуска не внедряем.
- Workspace агента: /srv/openhands-agent/work-workspace на хосте, /projects в контейнере. Конфигурация хранится отдельно в /srv/openhands-agent/config.
- AMNESIA, Nextcloud и остальные приложения находятся вне области изменений.

## Фактическое состояние

11 октября connector отключён штатным откатом; известные исполняемые компоненты broker удалены. Снимок, прежний образ и некоторые исходники остаются. Deployment в Git пока расходится с сервером и не предназначен для применения поверх текущей установки без согласования.

24 октября UI показывает default → gpt-5.5 (Active), work → deepseek-chat. Требуется изменить ссылку default через штатный редактор, после чего подтвердить выполнение задачи.
