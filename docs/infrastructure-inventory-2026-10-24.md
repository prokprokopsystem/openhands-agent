## Неустановленные факты

- Полный текущий список running и stopped контейнеров, образов, сетей, volumes и bind mounts.
- Службы вне Docker, ошибки systemd, timers и включённый автозапуск.
- Действующие порты, интерфейсы, ресурсы, диски и каталоги приложений.
- Был ли n8n позднее установлен или перенесён на mini-server; историческое размещение на VPS не доказывает сегодняшнее.
- Текущая версия и здоровье n8n на VPS: требуется отдельное чтение VPS, а не вывод по старому паспорту.
- Актуальность сертификатов и работоспособность приложений нельзя выводить из старых дат.

## Следующее действие

Пользователь выполняет один read-only блок по SSH на mini-server и присылает текст. Собрать Docker metadata по выбранным полям без environment/secrets, systemd services/timers/unit files, порты, диски/память, каталоги приложений и вручную отмеченные пакеты. Не запускать установку/обновление/очистку и не выполнять полное docker inspect с секретами.

После результата заполнить таблицу «установлено / работает / остановлено / назначение / данные / автозапуск» и отдельно определить судьбу существующего n8n на VPS. Не создавать вторую установку без решения пользователя.
