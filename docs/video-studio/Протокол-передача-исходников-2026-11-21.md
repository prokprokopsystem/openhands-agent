## 2. Каталог приёма исходников

Создан `/srv/video-studio-data/in/maloe-dobro`.

```
drwxrwsr-x 2 igor 10001 4096 /srv/video-studio-data/in/maloe-dobro
```

- владелец `igor` — тот, кто загружает;
- группа `10001` и бит `setgid`: загруженные файлы получают эту группу
  автоматически;
- контейнер работает от `10001:10001` и читает каталог как `/work` **только на
  чтение**.

Проверка записи: файл создан и удалён — ПРОЙДЕНО.
Проверка чтения контейнером: `ffprobe` от `10001:10001` прочитал файл из этого
каталога — ПРОЙДЕНО. Значит загруженные файлы будут видны ffmpeg без правок
владельца.

Оригиналы защищены самой привязкой: `/in` монтируется в контейнер как `/work`
с `read_only: true`. Монтаж физически не может изменить исходник.

## 3. Как передать файлы с Windows

Сервер: `192.168.100.106`, SSH на порту 22, пользователь `igor`.
Нужен тот же пароль или ключ, которым вы уже пользуетесь для этого сервера.

### Вариант A — без установки программ (PowerShell в Windows 10/11)

`scp` входит в Windows. Сначала положите клипы в простую папку без кириллицы,
например `C:\video-src`. Затем в PowerShell:

```powershell
# 1. Проверка связи
ssh igor@192.168.100.106 "echo OK"

# 2. Загрузка всех mp4 из папки
scp C:\video-src\*.mp4 igor@192.168.100.106:/srv/video-studio-data/in/maloe-dobro/

# 3. Проверка, что дошло
ssh igor@192.168.100.106 "ls -l /srv/video-studio-data/in/maloe-dobro"
```

Если имена содержат пробелы и `scp` ругается на `*`, грузите папку целиком:

```powershell
scp -r C:\video-src igor@192.168.100.106:/srv/video-studio-data/in/maloe-dobro/
```

Тогда файлы окажутся в `/in/maloe-dobro/video-src/` — это нормально,
инвентаризация смотрит вложенные каталоги.

### Вариант B — WinSCP или FileZilla (если уже установлены)

Протокол SFTP, хост `192.168.100.106`, порт 22, пользователь `igor`.
Справа открыть `/srv/video-studio-data/in/maloe-dobro` и перетащить файлы.

### Чего не делать

- Не копировать в `/home/igor` и вообще на системный диск: там 848 GiB свободно,
  но видео должно лежать на SSD.
- Не переименовывать файлы «по смыслу» — имена Google Flow нужны для сверки с
  раскадровкой. Порядок сцен задаётся монтажным планом, а не именем файла.
- Не загружать повторно то, что уже загружено: дубли ловятся по SHA-256, но
  лучше не плодить.

Если `ssh` не отвечает с вашего компьютера, причина почти всегда в `ufw` на
сервере или в другом сегменте сети. Это отдельная правка системных настроек и
без вашего разрешения не выполняется.

## 4. Инвентаризация после загрузки

Добавлен `stage-2a-ffmpeg/scripts/inventory-sources.sh`. Он:

- читает каталог только на чтение, в контейнере без сети;
- для каждого файла печатает размер, длительность, кодек, разрешение, fps,
  pix_fmt, параметры звука;
- считает SHA-256 и находит дубли по содержимому, а не по имени;
- отдельно отмечает файлы без звуковой дорожки;
- ничего не пишет на диск, только в stdout.

```
./scripts/inventory-sources.sh /srv/video-studio-data/in/maloe-dobro
```

## 5. План монтажа — заготовка до инвентаризации

Точные параметры будут взяты из инвентаризации: разрешение, fps и наличие звука
у клипов Google Flow пока не измерены на нашем сервере.

1. **Нормализация.** Каждый клип приводится к одному формату: H.264, `yuv420p`,
   одинаковые разрешение и fps, `setsar=1`, звук 48 кГц стерео AAC. Клипы Veo
   могут отличаться разрешением и частотой кадров; без нормализации склейка
   даёт рывки и рассинхрон.
2. **Сцена 3 (артефакты).** Обрезка по времени: оставить начало, где подъём
   листа читается, и убрать участок, где стержень появляется в руке. Точные
   границы определяются по кадрам, а не на глаз по названию файла.
3. **Склейка.** `concat`-фильтр после нормализации, без перекодирования
   дважды: нормализованные фрагменты пишутся в `/scratch` (внутри квоты
   хранилища), финал собирается из них.
4. **Звук.** Одна дорожка на весь фильм: музыка, обрезка по длине, плавное
   затухание в конце. Клипы Google Flow, скорее всего, без звука — тогда
   дорожка одна и общая.
5. **Выход.** `/out/maloe-dobro/v1.mp4`, версия в имени. Прошлые версии не
   перезаписываются.
6. **Проверка.** `ffprobe` финала: длительность, разрешение, fps, наличие
   аудиопотока, размер файла. Затем скачивание на Windows вашими руками.

HyperFrames для этого не нужен и не устанавливается.
