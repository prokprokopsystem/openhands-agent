## Зафиксированные режимы

### TEST MODE — реализован в текущем deployment, запуск ещё не выполнялся

- Жёсткая сетевая и файловая изоляция.
- Пустой `test-workspace`.
- Внутренние интеграции недоступны.

### WORK MODE — спроектирован, но не реализован

- Использует тот же Agent Canvas, systemd, supervisor, контейнер и базовый deployment.
- Подключается отдельным постоянным профилем разрешений и инструментов без переписывания базового deployment.
- Постоянно предоставляет n8n, разрешённые базы Notion, выделенные папки Nextcloud, AMNESIA и разрешённые операции GitHub.
- Обычные разрешённые действия не требуют ручного подтверждения каждого шага.
- Подтверждение требуется только для массового удаления, production deployment, операций с `main`, ключами, firewall, `sudo` и system services.
- Шлюз разрешений является техническим ограничителем полномочий, а не системой подтверждения каждой операции.
- Реализуется отдельным ограниченным этапом только после успешного TEST MODE.
