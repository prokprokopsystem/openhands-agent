## Что исправлено в финальной ревизии

- `restart: unless-stopped` удалён; единственный владелец жизненного цикла — systemd;
- systemd ждёт WireGuard с таймаутом, создаёт контейнер без запуска, применяет firewall и держит Compose в foreground;
- отдельные идемпотентные цепочки `OPENHANDS-EGRESS` и `OPENHANDS-INPUT` имеют явный порядок и финальный DROP;
- разрешены только DNS и внешний HTTP/HTTPS, внутренние сети, mini-server, VPS и остальные порты запрещены;
- egress-проверка выполняется из контейнера через `docker exec`;
- Docker health проверяет Canvas и внутренние listeners Agent Server/Automation;
- `config`, `secrets`, `test-workspace`, `logs` имеют mode 700, `.env` — 600;
- обычные start/stop выполняются только через systemd;
- purge удаляет также firewall и установленный unit, но требует явного подтверждения;
- `deployment/README.md` и дизайн теста синхронизированы.
