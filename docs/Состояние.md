Память грузится при `load_memory`, проектные правила `AGENTS.md` — при `load_project_skills`; в SDK оба флага по умолчанию `false`. **Проверено на живом разговоре:** при `load_memory: true` и `load_project_skills: true` оба уровня памяти и `AGENTS.md` попадают в системный промпт. **По коду фронтенда (запуском из UI не проверялось):** при создании разговора Canvas принудительно ставит `load_project_skills: true`, `load_user_skills: true`, `load_public_skills: false` и сохраняет `load_memory` из настроек. Вывод: разговор, созданный в обход UI (прямой POST без этих флагов или запуск по профилю), может остаться без памяти или без обязательных правил — такие запуски должны выставлять флаги сами.
- **Бюджет памяти:** общий предел 6000 символов на два уровня, при переполнении усекается верх (старое). Фактически: 2470 (user) + 1261 (project) = 3731 — усечения нет. Дневные журналы `YYYY-MM-DD.md` автоматически не грузятся.
- **Уборка:** проверочный разговор удалён после проверки; временные файлы проверки остались только в `/tmp` контейнера.
- **НЕ ПРОВЕРЕНО:** поведение памяти после перезапуска службы (перезапуск не выполнялся по указанию) и реальное усечение при переполнении бюджета.
