## Ключевые механизмы

- **Lifecycle:** systemd управляет контейнером и watchdog
- **Watchdog:** отслеживает docker healthcheck; 3×unhealthy → перезапуск через Restart=on-failure
- **Egress:** сеть разрешает только DNS и публичные HTTP/HTTPS; AMNESIA, Nextcloud, LAN — запрещены
- **Healthcheck:** `/canvas` (HTTP 200), backend — TCP-проверка доступности порта (НЕ равна функциональной readiness)
- **Runtime-проверка:** validate-runtime.sh перед каждым стартом
- **Главный вход:** systemd (start.sh — удобная оболочка для ручного теста)
- **LLM:** только через WebUI, не через env
