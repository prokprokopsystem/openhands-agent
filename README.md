# OpenHands Agent

Постоянный инженерный AI-агент на домашнем mini-server под Ubuntu.

## Перед началом работы

Любой агент обязан сначала прочитать корневой `AGENTS.md` и выполнять его правила.

## Назначение проекта

Agent Canvas предоставляет WebUI с телефона и компьютеров. Постоянные инструменты подключаются через независимый broker с ограниченными полномочиями, проверкой операций и аудитом.

AMNESIA, Nextcloud и остальная production-инфраструктура являются защищёнными системами и не должны изменяться вне явно разрешённых операций.

## Источники истины

- `AGENTS.md` — обязательный порядок работы;
- `docs/Состояние.md` — единственное место с текущим состоянием и следующим действием;
- `docs/План.md` — этапы проекта;
- `docs/Решения.md` — принятые архитектурные решения;
- `docs/Архитектура.md` — компоненты и границы;
- `deployment/README.md` — инструкция установки и эксплуатации.

README намеренно не повторяет текущий этап проекта. Актуальный статус всегда находится только в `docs/Состояние.md`.

Материалы аудита и исследования являются историей проекта, а не инструкциями по выполнению работ.

## Главное правило

Зафиксированное состояние считается актуальным до документированного изменения. После реального изменения код и документация обновляются вместе.
