# OpenHands Agent

Постоянный инженерный AI-агент на домашнем mini-server под Ubuntu.

## Перед началом работы

Любой агент обязан сначала прочитать корневой `AGENTS.md` и выполнять его правила.

## Назначение проекта

Agent Canvas предоставляет WebUI для простого исполнителя задач. Текущий курс — работа через DeepSeek без дополнительного broker/connector (DEC-023). Сохраняются Telegram и существующий автозапуск. Фактическая готовность и незавершённые действия описаны в `docs/Состояние.md`.

AMNESIA, Nextcloud и остальная production-инфраструктура являются защищёнными системами и не должны изменяться вне явно разрешённых операций.

## Источники истины

- `AGENTS.md` — обязательный порядок работы;
- `docs/Состояние.md` — текущее состояние **самого OpenHands** и указатели на отдельные проекты;
- [`docs/video-studio/ТЕКУЩЕЕ-СОСТОЯНИЕ.md`](docs/video-studio/ТЕКУЩЕЕ-СОСТОЯНИЕ.md) — **единственный актуальный статус AI-видеостудии** (SSD, FFmpeg, исходники, монтаж и следующий шаг);
- `docs/План.md` — этапы проекта;
- `docs/Решения.md` — принятые архитектурные решения;
- `docs/Архитектура.md` — компоненты и границы;
- `deployment/README.md` — инструкция установки и эксплуатации.

README намеренно не повторяет текущий этап проекта. Состояние **OpenHands** хранится в `docs/Состояние.md`, а **видеостудии** — только в `docs/video-studio/ТЕКУЩЕЕ-СОСТОЯНИЕ.md`. Не подменять текущий статус датированными историческими отчётами.

Материалы аудита и исследования являются историей проекта, а не инструкциями по выполнению работ.

Зафиксированное состояние считается актуальным до документированного изменения. После реального изменения код и документация обновляются вместе.
