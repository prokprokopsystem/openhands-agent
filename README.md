# OpenHands Agent

Проект персонального инженерного AI-агента, размещённого на домашнем mini-server под Ubuntu.

## Цель

Создать агента лучше и надёжнее текущего Hermes: с удобным веб-интерфейсом, множеством подключаемых инструментов и возможностью помогать в автоматизации, разработке других агентов, проектировании workflow n8n и работе с GitHub, Nextcloud, Notion, Docker, SSH и другой существующей инфраструктурой.

## Основные требования

- одинаковый удобный интерфейс с домашнего компьютера, рабочего компьютера и телефона;
- работа через браузер, без обязательного использования консоли;
- интерфейс, похожий по удобству на ChatGPT;
- ввод текстом, голосом, вставкой из буфера, файлами и фотографиями;
- размещение на домашнем mini-server;
- использование внешних LLM через API, с возможностью менять провайдеров и модели;
- расширяемая система инструментов и интеграций;
- безопасная работа в изолированной среде;
- отдельные права для чтения, изменения и опасных операций;
- подтверждение пользователем перед необратимыми действиями;
- устойчивость к зависаниям, перезапуск после сбоев и понятный журнал действий.

## Границы проекта

AMNESIA является отдельным проектом и не изменяется. Папка `Инфраструктура` в репозитории `amnesia-next` используется только как паспорт существующей среды: серверы, сети, Docker, WireGuard, Nextcloud, n8n, домены, порты, SSH и другие доступные ресурсы.

## Принцип архитектуры

Система должна быть модульной. OpenHands рассматривается как инженерное ядро, но интерфейс, голос, интеграции, модели и инструменты не должны быть навсегда привязаны к одному компоненту. Если позже появится агент лучше OpenHands, инженерное ядро можно будет заменить без перестройки всей системы.

## Текущий статус

Проект находится на этапе проектирования. До установки необходимо:

1. изучить актуальные возможности OpenHands;
2. извлечь из паспорта инфраструктуры фактическую схему среды;
3. выбрать архитектуру интерфейса и удалённого доступа;
4. определить модель разрешений для инструментов;
5. составить поэтапный план установки, тестирования и отката.

Подробности находятся в папке `docs`.
