# OpenHands Agent

Проект постоянного инженерного AI-агента на домашнем mini-server под Ubuntu.

## Цель

Дать пользователю устойчивый WebUI с телефона и компьютеров, через который агент сможет выполнять длинные инженерные задачи, работать с кодом и файлами, сохранять состояние и позднее подключаться к GitHub, SSH, Docker, n8n, Nextcloud и Notion через независимый контролируемый шлюз разрешений.

## Границы

AMNESIA, Nextcloud и production-инфраструктура являются отдельными защищёнными системами. Первый тест не получает к ним файлового, SSH-, Docker- или API-доступа.

## Архитектурный принцип

Agent Canvas — первый интерфейс и инженерное ядро, но не вечная зависимость. Backend-агент и модели должны заменяться без перестройки слоя доступа и разрешений.

## Текущий статус

Завершены:

- инвентаризация mini-server;
- исследование Agent Canvas 1.6.1;
- проектирование первого изолированного теста;
- финальная ревизия Compose, systemd, healthcheck, egress-firewall и инструкций.

Не выполнялись:

- установка на mini-server;
- скачивание и запуск образа;
- применение firewall;
- первый тест.

Перед реальным запуском нужен независимый просмотр итогового diff и отдельное разрешение пользователя.
